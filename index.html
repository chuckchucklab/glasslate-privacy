한국어

시행일: 2026년 8월 16일

Glasslate(이하 "이 앱")는 화면에 보이는 외국어 텍스트를 인식해 번역문을 겹쳐 보여주는 Android 앱입니다. 이 방침은 이 앱이 어떤 데이터를 다루고, 무엇을 기기 밖으로 내보내지 않는지 설명합니다.

1. 이 앱이 화면 내용을 다루는 방식

이 앱은 사용자가 명시적으로 허용했을 때만 Android의 화면 공유(MediaProjection) 기능으로 화면을 캡처합니다. 캡처된 화면은 다음과 같이 처리됩니다.

  • 캡처 이미지는 기기 메모리에서만 처리되며, 처리 직후 해제됩니다.
  • 인식된 텍스트, 번역문, 텍스트 위치 좌표는 메모리에만 존재하며 앱을 종료하면 사라집니다.
  • 이 중 어느 것도 저장 장치에 기록되지 않고, 어느 것도 서버로 전송되지 않습니다.
  • 문자 인식과 번역은 기기에 설치된 온디바이스 모델로 수행됩니다.

화면 공유는 알림 영역의 정지 버튼, 앱 내 Stop, 또는 Android 시스템의 공유 중지로 언제든 끝낼 수 있습니다.

2. 기기에 저장되는 것

선택한 모드전체 화면 / 선택 영역

이 값들은 클라우드 백업과 기기 간 이전에서 제외되도록 설정되어 있으며, 앱을 삭제하면 함께 삭제됩니다.

3. 네트워크 사용

이 앱은 두 가지 목적으로만 네트워크를 사용합니다.

(1) 언어 모델 및 문자 인식 모듈 다운로드
번역 모델과 일부 문자권(중국어·일본어·한국어)의 인식 모듈은 최초 1회 다운로드가 필요합니다. 다운로드는 Wi-Fi 연결에서만 수행됩니다. 이 통신에는 화면 내용이 포함되지 않습니다.

(2) Google ML Kit SDK의 진단 데이터 전송
이 앱은 문자 인식·언어 판정·번역에 Google의 ML Kit SDK를 사용합니다. ML Kit SDK는 Google의 공개 정책에 따라 다음과 같은 비내용 진단 데이터를 Google로 전송합니다.

  • 기기 정보(제조사, 모델, 운영체제, 하드웨어 가속기)
  • 앱 패키지명과 버전
  • 설치별 식별자
  • 처리 지연 시간 등 성능 지표
  • 처리 요청의 설정값과 입력·출력의 크기
  • 이벤트 유형과 오류 코드
  • 판정된 원본 언어와 설정된 번역 언어

마지막 항목에 대해 분명히 밝힙니다. 이 앱은 원본 언어를 사용자에게 묻지 않고 화면을 보고 자동으로 판정하므로, "어떤 언어로 된 화면을 보고 있는지"에 해당하는 언어 종류가 Google로 전달됩니다. 화면의 실제 내용(이미지·문장·번역문)은 전송되지 않지만, 언어 종류는 전송됩니다. 이 전송은 ML Kit SDK가 수행하며 앱이 끄거나 사용자가 거부할 수 있는 수단은 제공되지 않습니다.

ML Kit의 데이터 처리에 대한 Google의 공식 설명: https://developers.google.com/ml-kit/android-data-disclosure

이 두 가지 외에 이 앱이 구현한 네트워크 업로드는 없습니다. 광고 SDK, 분석 SDK, 크래시 리포터를 포함하지 않습니다.

4. 이 앱이 하지 않는 것

  • 화면 캡처 이미지를 저장하거나 전송하지 않습니다.
  • 인식된 텍스트와 번역문을 저장하거나 전송하지 않습니다.
  • 계정을 만들지 않으며 로그인을 요구하지 않습니다.
  • 연락처, 위치, 통화 기록, 파일에 접근하지 않습니다.
  • 광고를 표시하지 않고 데이터를 판매하지 않습니다.

6. 번역되지 않는 화면이 있습니다

일부 앱은 보안을 위해 자신의 화면이 캡처되지 않도록 설정합니다(예: 은행, 결제, 저작권 보호 영상). 또 일부 앱은 자신 위에 다른 앱의 오버레이가 표시되지 않도록 요청합니다.

이 앱은 그러한 보호를 우회하지 않습니다. 해당 화면에서는 번역이 동작하지 않으며 앱이 그 사실을 알려줍니다. 이는 고장이 아니라 의도된 동작입니다.

7. 아동

이 앱은 만 13세 미만 아동을 대상으로 하지 않으며 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 변경

이 방침이 변경되면 이 문서의 시행일이 갱신되며, 중요한 변경은 앱 업데이트 설명에 함께 안내합니다.

English

Effective date: 16 August 2026

Glasslate ("the app") recognizes foreign-language text on your screen and displays translations over it. This policy explains what the app does with that data, and what never leaves your device.

1. How the app handles screen content

The app captures your screen using Android's MediaProjection only after you explicitly grant it. Captured screens are handled as follows:

  • Captured images are processed in device memory only and released immediately afterwards.
  • Recognized text, translations, and text positions exist in memory only and are gone when the app stops.
  • None of it is written to storage, and none of it is sent to any server.
  • Text recognition and translation run on on-device models.

You can end screen sharing at any time from the notification, the in-app Stop control, or Android's own sharing indicator.

2. What is stored on your device

Selected target languageko, en

They are excluded from cloud backup and device-to-device transfer, and are deleted when you uninstall the app.

3. Network use

The app uses the network for two purposes only.

(1) Downloading language models and text recognition modules
Translation models and the recognition modules for some scripts (Chinese, Japanese, Korean) require a one-time download, performed over Wi-Fi only. No screen content is included in this traffic.

(2) Diagnostic data sent by the Google ML Kit SDK
The app uses Google's ML Kit SDK for text recognition, language identification, and translation. Per Google's published policy, the ML Kit SDK transmits the following non-content diagnostic data to Google:

  • Device information (manufacturer, model, OS, hardware accelerators)
  • App package name and version
  • Per-installation identifiers
  • Performance metrics such as processing latency
  • Request configuration and the size of inputs and outputs
  • Event types and error codes
  • The detected source language and the configured translation language

To be explicit about that last item: the app never asks you to pick a source language — it detects it from your screen. So the language you are reading is transmitted to Google. The actual content of your screen (images, sentences, translations) is not transmitted, but the language is. This transmission is performed by the ML Kit SDK, and neither the app nor you are offered a way to disable it.

Google's official disclosure: https://developers.google.com/ml-kit/android-data-disclosure

Beyond these two, the app implements no network upload of any kind. It contains no advertising SDK, no analytics SDK, and no crash reporter.

4. What the app does not do

  • Does not store or transmit screen captures.
  • Does not store or transmit recognized text or translations.
  • Does not create accounts or require sign-in.
  • Does not access contacts, location, call logs, or files.
  • Shows no ads and sells no data.

Screen sharing is not an Android permission — it is a system consent confirmed each time you start.

6. Some screens will not be translated

Some apps mark their screens as protected from capture (banking, payments, DRM-protected video). Some apps also ask the system to hide overlays drawn on top of them.

This app does not circumvent those protections. Translation will not work on such screens, and the app tells you so. This is intended behavior, not a defect.

7. Children

The app is not directed to children under 13 and does not knowingly collect personal information from children.

8. Changes

If this policy changes, the effective date above is updated, and significant changes are noted in the app's update description.
